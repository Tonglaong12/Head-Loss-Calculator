Head Loss Calculator / โปรแกรมคำนวณ Head Loss

By. Tonglaong

Friction loss in pipe (Darcy–Weisbach, Swamee–Jain) and total head for pump selection

Theory / ทฤษฎีและสูตรที่ใช้

แอปนี้คำนวณ Head loss ในท่อด้วยสมการ Darcy–Weisbach และหา friction factor ด้วยสมการ Swamee–Jain

1. Total Head

Total Head = H_geo + H_pressure + H_velocity + Hf × (1 + margin%) Option: Total Head = (H_geo + H_pressure + H_velocity + Hf) × (1 + margin%)

H_geo = ระยะแนวดิ่ง, H_pressure = แรงดันปลายทาง, H_velocity = velocity head ที่กรอก, Hf = friction loss ในท่อ (หน่วยเมตร)

2. Velocity and Reynolds number

V = Q / A = 4Q / (π D²) (Q in m³/s, D in m) Re = V × D / ν (1 cSt = 1×10⁻⁶ m²/s)

3. Darcy–Weisbach equation

Hf = f × (L / D) × V² / (2g) Hf = f × 8 L Q² / (π² g D⁵) (same equation, written with Q)

f = Darcy friction factor, L = pipe length (m), D = inside diameter (m), g = 9.81 m/s². สมการนี้ใช้ได้กับของไหลทุกชนิดและทุกช่วงการไหล (laminar, transitional, turbulent)

4. Friction factor (f)

Laminar (Re < 3000): f = 64 / Re Turbulent (Swamee–Jain): f = 0.25 / [ log10( ε / (3.7 D) + 5.74 / Re^0.9 ) ]²

ε = absolute roughness (m). Swamee–Jain เป็นสูตรแบบ explicit ที่ประมาณสมการ Colebrook–White ได้ภายในราว 1% จึงไม่ต้องคำนวณวนซ้ำ. ช่วงที่ใช้แม่นโดยทั่วไปคือ Re ราว 5,000–10⁸ และ ε/D ราว 10⁻⁶–10⁻². แอปสลับไปใช้สูตร laminar ที่ Re < 3000 ตามไฟล์ Excel

5. Safety margin

Hf (design) = Hf × (1 + margin% / 100) e.g. 15% → × 1.15

6. Pipe roughness (ε) used

Plastic0.015 mm (1.5×10⁻⁵ m)
Steel0.045 mm (4.5×10⁻⁵ m)
Fibreglass (Generic)0.030 mm (3.0×10⁻⁵ m)
Flowtite GRP0.029 mm (2.9×10⁻⁵ m)

Values are taken from the Excel file.

7. Worked example

Q = 20 m³/h, D = 80 mm, Steel, L = 68 m, margin 15% V = 1.105 m/s Re = 88,419 f = 0.0210 Hf = 1.112 m → × 1.15 = 1.278 m

8. Assumptions and limits

  • Water at ν = 1 cSt (default, editable), g = 9.81 m/s².
  • By default L is the horizontal length only, as in the Excel file. Tick "Include vertical pipe in length L" to add the vertical height to L.
  • Losses from fittings and valves are not included.
  • The diameter is used as the inside diameter. Nominal size can differ from the real inside diameter.
  • The 2.5 m/s velocity limit is a check taken from the Excel file.
  • The result is an estimate for pump selection. Please verify before final design.
